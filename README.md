sepatu# 🛒 E-Commerce Shoes — Panel Admin

Proyek ini berisi fitur CRUD untuk mengelola data pada aplikasi E-Commerce Shoes.

## ✅ Fitur
- **Create:** Menambahkan data baru
- **Read:** Menampilkan daftar data
- **Update:** Mengubah data
- **Delete:** Menghapus data

## 🛠️ Teknologi
- Bahasa: PHP
- Database: MySQL — `e_commerce_shoes`
- Server: XAMPP

## 📂 Struktur Database

| No | Nama Tabel | Keterangan |
|----|------------|------------|
| 1 | `brands` | Data merek sepatu |
| 2 | `categories` | Kategori produk |
| 3 | `customers` | Data pelanggan |
| 4 | `carts` | Keranjang belanja |
| 5 | `cart_items` | Detail isi keranjang |
| 6 | `products` | Data produk/sepatu |
| 7 | `orders` | Data pesanan |
| 8 | `order_items` | Detail pesanan |
| 9 | `payments` | Data pembayaran |
| 10 | `users` | Data pengguna/admin |
